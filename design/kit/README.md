# WallePlayer — design kit

Based on the user-selected exec-c53e16ab-6ce6-4938-922f-3a005c14cdd7.png reference, not the later separated-eye variants.

- `svg/mark.svg`: transparent standalone head, editable vector paths.
- `svg/app-icon.svg`: rounded tile with transparent outer corners.
- `svg/app-icon-full-bleed.svg`: square tile for OS-controlled masking.
- `svg/wordmark-*.svg`: horizontal logo variants; text outlined.
- `svg/lockup-stacked.svg`: stacked logo.
- `svg/mono-*.svg`: single-color logo with transparent negative spaces.
- `designs/`: desktop, mobile and compact player visual concepts.
- `brand-board.svg`: identity overview.
- `png/`: raster exports and Windows ICO.
- `index.html`: local gallery. UI concepts are not functional music players.

Palette: Carbon #111113, Ochre #D5A52C, Warm white #E6E3DA.
Typography: Segoe UI Regular / Bold, outlined in all SVG exports. No embedded fonts or raster images in SVG.

The logo is a hand-reconstructed vector approximation of the selected raster silhouette. Raster texture/lighting is intentionally removed for flat fills. Original reference is kept in reference/.
