# Walle Player — история версий

**Одна версия продукта** для Windows-программы и Android-приложения (WallePlayerMobile, `pubspec.yaml`): общие выпуски
выходят с одинаковым номером (`WallePlayer-Setup-0.4.0.exe` и `WallePlayer-0.4.0.apk`); исправление только одной части —
третья цифра (0.4.1) только у неё. Версия Windows-программы — в `musicplayer/__init__.py` (`__version__`) и
`pyproject.toml`; поднимается при каждом заметном изменении. Сборки — в папку на Google Drive (rclone `walle-builds:`).
Сервер сообщает её клиентам (`/api/ping`): открытый веб-плеер предлагает «Обновить», мобильное приложение сверяет
`api` / `api_min` и предлагает новую версию себя, если её APK лежит в `%LOCALAPPDATA%\WallePlayer\mobile`.

## 0.4.10 — 2026-10-09

Только Windows-программа (сервер библиотеки).
- Доступ из интернета по **https** через свой VPS: на сервере Caddy с бесплатным сертификатом (имя вида
  `203-0-113-10.sslip.io`, регистрировать ничего не нужно), туннель открыт только внутри сервера — ключ больше не идёт
  открытым текстом; защита от подбора снова видит настоящий адрес каждого посетителя. В «Свой сервер (VPS)» —
  поле «HTTPS-имя» и кнопка «Скопировать команду https (Caddy)».
- Туннель к VPS больше не переживает программу (привязан к её процессу): после перезапуска не остаётся старого
  туннеля, занимающего порт на сервере.

## 0.4.9 — 2026-10-09

Windows-программа.
- Программа и установщик подписаны своим сертификатом «Walle Player» (с меткой времени). Чтобы Windows показывала издателя «Walle Player» вместо «Неизвестный издатель», на компьютере один раз устанавливается `WallePlayer.cer` (лежит рядом с установщиком): двойной клик → «Установить сертификат» → «Локальный компьютер» → хранилища «Доверенные корневые центры сертификации» и «Доверенные издатели».

## Мобильное приложение 0.4.7 — 2026-10-08

- Без связи приложение больше не выкидывает на экран подключения; список библиотек хранится ещё и запасной копией в

## Мобильное приложение 0.4.6 — 2026-10-08

Android (versionCode 2005); iOS — пока 0.4.0.
- Адреса из интернета приходят с компьютера сами: вне дома телефон подключается без нового QR (все адреса пробуются
  параллельно, выигрывает первый ответивший); поддержаны IPv6-адреса.
- Если сервер заблокировал адрес за подбор ключа — понятное сообщение «подождите N минут», без лишних запросов.
- Метки скачанных треков (лайки, настроения, жанры) обновляются при подключении, аудио не перекачивается.

## 0.4.6 — 2026-10-08

Только Windows-программа (сервер библиотеки).
- `/api/info` сообщает все адреса библиотеки — домашние и внешние: приложение, подключённое дома, узнаёт адрес для
  интернета само, второй QR не нужен (нужна поддержка в приложении).

## 0.4.5 — 2026-10-08

Только Windows-программа (сервер библиотеки).
- «Из интернета» — выбор способа в «Другие устройства»:
  - **Статический IP — через роутер**: программа сама находит роутер, узнаёт его внешний адрес, открывает порт
    (UPnP) и закрывает при выходе; «серый» адрес провайдера распознаётся и в QR не попадает; можно указать DDNS-имя.
  - **Свой сервер (VPS) — туннель**: обратный SSH-туннель встроенным ssh Windows, ключ создаётся сам («Скопировать
    ключ для сервера», «Скопировать команду настройки»), переподключение при обрыве, понятные ошибки.
  - **Свой адрес** (KeenDNS, сервис-туннель) — как раньше.
- Защита от подбора работает и для тех, кто приходит через VPS (общая метка, бан на 10 минут).

## 0.4.4 — 2026-10-08

Только Windows-программа (сервер библиотеки).
- Защита от подбора ключа (как fail2ban): 10 неверных ключей за 10 минут — адрес блокируется на час, повторно — на 4 ч,
  16 ч, … до недели; заблокированный не получает вообще ничего; IPv6 блокируется подсетью /64; блокировки переживают
  перезапуск; в «Другие устройства» видно, кто заблокирован, кнопка «Снять блокировки»; уведомление из трея.

## 0.4.3 — 2026-10-08

Только Windows-программа (сервер библиотеки).
- Доступ из интернета по IPv6: сервер слушает IPv4 и IPv6, в «Другие устройства» появляется адрес «Из интернета (IPv6)»
  (нужен IPv6 у провайдера и в роутере — см. docs/internet-access.md, раздел 0).
- У каждого слушателя «Моя волна» («Любимое», «Незнакомое», «не повторять недавнее») и сортировки «Часто слушаю» /
  «Чаще редкие» / «давно не слушал» считаются по его собственным прослушиваниям.

## 0.4.2 — 2026-10-08

Только Windows-программа (веб-плеер, который она раздаёт телефонам).
- Веб-плеер без связи с компьютером: «Волна», «Музыка», «Исполнители», «Альбомы», «Плейлисты», страницы исполнителя, альбома и плейлиста работают по скачанному на устройство; то, что нельзя послушать, не показывается (в очереди тоже); кнопки «Нравится», «Разметить», «Скачать» скрыты до восстановления связи; связь вернулась — полные страницы возвращаются сами.
- Плейлисты запоминаются на устройстве, когда их открывают при связи.
- Строки списков (плейлисты, исполнители) выровнены по левому краю.

## 0.4.1 — 2026-10-08

Только Windows-программа.
- Сканирование, обучение модели настроений и разметка библиотеки идут в отдельном процессе: плеер, окно и сервер библиотеки (телефоны) больше не подвисают, пока они работают.
- Сканирование записывает изменения короткими порциями: прослушивания и метки с компьютера и телефона сохраняются сразу, а не после конца скана.
- Модель: учёт жанра и исполнителя, связи настроений (метал/панк → «Тяжёлое», спокойный инструментал → «Ночное», «Фоновое»), дескрипторы v2; «Дообучить» сам досчитывает отпечатки CLAP; счётчик новых меток.

## 0.4.0 — 2026-10-08

Общий выпуск с Android-приложением: версии выровнены (Windows-программа и приложение — 0.4.0).
- Установщик для Windows (без прав администратора, ярлыки, удаление; данные библиотеки не трогает).
- Для приложения: повторно отправленное прослушивание (тот же `uid`) засчитывается один раз; уменьшенные обложки
  `?size=`; отпечаток `rev` у «Любимых» и плейлистов для офлайн-синхронизации; задокументированы `/genres`, `/logout`.

## 0.3.0 — 2026-10-08

**Библиотека на других устройствах**
- Сервер библиотеки (порт 8780, кнопка «Другие устройства»): веб-плеер для телефона в том же оформлении — Моя волна
  (настроения, жанры, характер), музыка, исполнители, альбомы, плейлисты, лайки, перемотка, экран блокировки.
- Слушатели: у каждого свой QR, лайки и история; ваше «Избранное» и статистика не смешиваются. Разметку гостю можно
  разрешить. Переименование с телефона и в программе.
- Новые устройства просят доступ по имени, вы разрешаете в программе (новым слушателем или своим устройством).
- Разметка с телефона как в ленте: настроения с уверенностью модели, тип записи, язык, голос, жанр, эпоха.
- «Скачать» на устройство и игра без связи (в т.ч. волна по настроениям из скачанного); метки скачанного обновляются
  без перекачки; прослушивания без связи отправляются позже.
- Видно буферизацию и обрыв связи; после восстановления трек продолжается с того же места.
- Внешний адрес для доступа из интернета (KeenDNS, свой VPS…), см. docs/internet-access.md.
- Walle Player в трее: пока библиотека открыта, закрытие окна сворачивает в трей; запуск вместе с Windows.
- Занятый порт — сервер сам берёт соседний; окно предупреждает про общественную сеть и брандмауэр.
- Версии и уведомления об обновлении (этот файл).
- Адрес библиотеки не «слетает»: занятый порт заменяется только на один запуск; у библиотеки постоянный id,
  по нему приложение находит компьютер, если сменился IP.
